## Melden

Meld problemen of verzoeken via de issues in deze repository. Beschrijf het probleem zo duidelijk mogelijk, inclusief stappen om te herhalen waar dat mogelijk is.

## Bouwen

Bouw het project met de standaardcommando's die in de readme worden beschreven. Zorg ervoor dat alle benodigde afhankelijkheden geïnstalleerd zijn voordat je begint.

## Reviewen

Veranderingen worden beoordeeld door een maintainer voordat ze worden opgenomen. Zorg ervoor dat je test toevoegt en dat alle bestaande tests nog slaagen bij het indienen van je bijdrage.
